# Pearl Rig Control & Watchdog Agent (Dual RTX 4070 Ti)

Комплексная система полного контроля и управления майнингом монеты **Pearl (`pearlhash`)** для твоего ПК с двумя **NVIDIA RTX 4070 Ti**, включающая веб-консоль управления, живой мост к локальному API `onezerominer` (`127.0.0.1:3001`), автоматический обход VPN (`INCY TUN` / `NashVPN`), защиту видеокарт и двустороннее управление через Telegram-бота.

## User Review & Critical Decisions

> [!IMPORTANT]
> По результатам твоих ответов выбран режим **полного контроля и управления**, объединяющий все уровни защиты и дистанционного доступа.

- **Подтверждённое решение 1 (Архитектура полного контроля)**: Веб-панель управления + готовый автономный Windows Watchdog-агент (`.ps1` + `.bat` лаунчер с автоправами Администратора) + встроенный в агента контроллер Telegram-бота.
- **Подтверждённое решение 2 (Сетевой иммунитет к VPN)**: Каждые 15 секунд агент проверяет таблицу маршрутизации Windows и DNS (`hosts`), удерживая прямые `/32` маршруты до `prl.kryptex.network` и `prl-eu.kryptex.network` через домашний роутер в обход `INCY TUN`, даже если ты переключаешь страну/сервер в VPN.
- **Подтверждённое решение 3 (Аппаратная защита и самовосстановление)**: Контроль хешрейта обеих RTX 4070 Ti через API `127.0.0.1:3001`, автоматический перезапуск при `0 H/s` или зависании пула, ступенчатая защита от перегрева (авто-снижение Power Limit при превышении порога температуры) и валидация 63-символьного адреса кошелька `prl1p...`.

## 1. Overview & Core Concept

- **Что делает система**:
  1. **Веб-консоль управления ригом**: позволяет в реальном времени подключаться к локальному API `onezerominer` (`127.0.0.1:3001`) или вставлять/анализировать лог `pearl-miner.log`, настраивать профили разгона для `GPU 0` и `GPU 1` (RTX 4070 Ti), проверять корректность адреса кошелька `prl1...`, настраивать пороги температур и команды Telegram-бота.
  2. **Генератор автономного Watchdog-агента для ПК**: формирует готовый пакет запуска (`start_pearl_agent.bat` с интегрированным фоновым PowerShell-супервизором), который берёт под полный контроль процесс `onezerominer.exe`, сетевые маршруты в обход VPN и связь с Telegram.
- **Целевая конфигурация**: Windows ПК, 2× NVIDIA RTX 4070 Ti (`dual4070ti`), майнер `onezerominer-win64-1.8.3`, пул `prl.kryptex.network` (`7048` / `8048`), VPN-клиент `INCY` (`TUN`).
- **Ключевая ценность**: Майнинг работает без простоев 24/7 независимо от включения/переключения VPN, а ты можешь контролировать риг и переключать профили как из браузера, так и со смартфона через Telegram (`/status`, `/restart`, `/vpn_fix`, `/oc_eco`, `/oc_max`, `/stop`).

## 2. User Experience & Visual Design

- **Ключевые пользовательские сценарии**:
  1. **Дашборд телеметрии и управления (`Мониторинг и Управление`)**:
     - Отображение сводной статистики рига `dual4070ti` (суммарный хешрейт, принятые/отклонённые шары, аптайм, энергопотребление и эффективность `H/W`).
     - Покарточный контроль обеих карт **GPU 0 (RTX 4070 Ti)** и **GPU 1 (RTX 4070 Ti)**: частоты ядра (`2400 MHz`), памяти (`810 MHz`), Power Limit (`150 W`), обороты кулеров (`65%`) и температура с цветовой индикацией состояния.
     - Переключение режима: прямое чтение локального API `http://127.0.0.1:3001`, разбор вставленного лога `pearl-miner.log` или интерактивное тестирование сценариев сбоя (тайм-аут VPN, падение хешрейта, перегрев).
  2. **Конфигуратор профилей и валидатор кошелька (`Настройка Рига и Разгона`)**:
     - Встроенная проверка длины и формата адреса `prl1p...` (предупреждение, если адрес короче 63 символов, как было в исходном батнике `[REMOVED_LOCAL_WALLET]`).
     - Быстрые пресеты для RTX 4070 Ti на алгоритме `pearlhash`: *Эко (135W / 2250 MHz)*, *Оптимальный (150W / 2400 MHz)* и *Максимум (185W / 2610 MHz)*.
  3. **Сетевой щит анти-VPN и диагностика (`Анти-VPN & Сеть`)**:
     - Настройка списка пулов (`prl.kryptex.network:7048`, `prl-eu.kryptex.network:8048`) и DoH-резолвера для обхода Fake-IP (`198.18.x.x`) в `INCY TUN`.
  4. **Telegram-контроллер и выгрузка агента (`Watchdog Агент & Telegram`)**:
     - Ввод `Bot Token` и `Chat ID` с кнопкой мгновенной тестовой отправки уведомления прямо из браузера в твой Telegram.
     - Скачивание в 1 клик готового файла `pearl_watchdog_agent.bat`, который заменяет старый батник и запускает полный цикл защиты.

- **Визуальный стиль и тема**:
  - *Aesthetic Direction*: Индустриальная инженерная консоль мониторинга оборудования (Utilitarian Hardware Telemetry Console) с высокой плотностью данных и мгновенной считываемостью.
  - *Color Palette & Mood*: Строгая тёмная сланцевая палитра (`#0B0F17` основной холст, `#111827` структурные панели, `#1F2937` тонкие 1px границы), акцентный изумрудный (`#10B981`) для штатной работы, янтарный (`#F59E0B`) для предупреждений (обрыв маршрута / урезанный кошелёк) и рубиновый (`#EF4444`) для критических сбоев.
  - *Typography & Hierarchy*: Заголовки и навигация — `Outfit` / `Plus Jakarta Sans`; основной интерфейс — `Plus Jakarta Sans`; вся телеметрия, частоты, хешрейт, лог-консоль и таймеры — строго моноширинный `JetBrains Mono` с табличными цифрами (`tabular-nums`).
  - *Component Styling & Layout*: Полноэкранный десктопный макет (1440px) с левой навигационной панелью (260px), верхней строкой по контракту 3 зон (название рига, навигация по вкладкам, кнопка скачивания обновлённого агента) и одноуровневыми карточками с тонкими границами 1px без вложенных контейнеров.

## 3. Key Product Decisions & Trade-Offs

- **Решение 1: Единый самодостаточный `.bat` + PowerShell Watchdog без внешних зависимостей**
  - *Выбранный подход*: Скрипт агента упакован в один `.bat` файл, который автоматически запрашивает права Администратора, распаковывает и запускает свой PowerShell-движок и управляет `onezerominer.exe`.
  - *Почему*: Работает на любой Windows 10/11 сразу из коробки, имеет прямой доступ к таблицам маршрутизации `route.exe`, файлу `hosts`, `nvidia-smi` и локальному API `127.0.0.1:3001`.
- **Решение 2: Двухуровневый обход VPN (`DoH + /32 Static Routes`)**
  - *Выбранный подход*: Вместо флага `--proxy` (который блокируется серверами `NashVPN`) агент получает реальные IP пула через Google DNS-over-HTTPS, фиксирует их в `hosts` (чтобы `INCY TUN` не подсовывал Fake-IP `198.18.x.x`) и создаёт маршруты `/32` напрямую через шлюз домашнего роутера.
  - *Почему*: Маршрут с маской `255.255.255.255` (`/32`) в Windows имеет абсолютный приоритет над маршрутами виртуального адаптера `TUN`, поэтому VPN остаётся включённым для всех программ, а майнер идёт напрямую без потерь пинга.
- **Решение 3: Двустороннее управление через Telegram Bot API без выделенного сервера**
  - *Выбранный подход*: Локальный Watchdog-агент использует `getUpdates` и `sendMessage` напрямую к `api.telegram.org`, позволяя принимать команды (`/status`, `/restart`, `/vpn_fix`, `/stop`) и слать алерты прямо с твоего ПК.
  - *Почему*: Не требует внешнего хостинга или проброса портов на роутере.

### Data Model & State
- **Конфигурация рига (`RigConfig`)**: пути к папке `onezerominer-win64-1.8.3` и лог-файлу `pearl-miner.log`, адрес кошелька `prl1...` с индикатором валидности, основной и резервный пулы, параметры по каждой карте (`cclk`, `mclk`, `pl`, `fan`, `kernel`).
- **Политика Watchdog (`WatchdogPolicy`)**: интервал проверки (сек), порог минимального хешрейта, максимальная температура GPU (°C) для аварийного снижения Power Limit, авто-восстановление маршрутов при смене VPN-сервера, настройки Telegram (`botToken`, `chatId`).
- **Живая телеметрия (`TelemetryState`)**: состояние подключения к `127.0.0.1:3001`, метрики GPU 0 и GPU 1, история событий самовосстановления и симулятор/парсер реальных строк лога `onezerominer`.
