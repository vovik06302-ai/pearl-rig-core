# Pearl Rig Control for Windows

Продукт запускается как нативное окно Windows Forms. Ярлык установщика открывает
`pearl_watchdog_agent.bat`; запуск браузерной панели не используется.

Окно показывает живые показатели OneZeroMiner API (`127.0.0.1:3001`) и датчики
`nvidia-smi`: хешрейт, шары, температуры, частоты, вентиляторы и мощность каждой
карты. При недоступном источнике отображается «нет данных».

Баланс PRL загружается из Kryptex: подтверждённые, ожидающие и общие начисления.
Рублёвый эквивалент помечен как оценка по рыночному курсу PRL/USD Kryptex и USD/RUB
Банка России. Панель не подменяет баланс прогнозами заработка. Общая мощность —
сумма показаний двух GPU; накопление кВт·ч ведётся локально по замерам мощности
GPU и не является показанием бытового счётчика. Тариф электричества задаёт
пользователь и сохраняет на этом ПК.

Кнопка «ОБНОВИТЬ ДАННЫЕ» запрашивает свежую телеметрию, баланс и курс. Кнопка
«ПОЛНЫЙ ЭКРАН» разворачивает нативное окно; выход — `Esc` или та же кнопка.
Настройки кошелька, тарифа и накопленной энергии хранятся в `%LOCALAPPDATA%` и
не публикуются в репозитории.

Версия программы показана рядом с кнопкой обновлений. При открытии окна и по
нажатию кнопки программа проверяет GitHub Releases; если вышла новая версия,
показывает номер и кнопку скачивания. Установщик скачивается в фоне с цветной
шкалой прогресса, а запуск установки подтверждается отдельным запросом.

Кнопка режима переключает ручной запуск и автозапуск майнера при следующем входе
в Windows. Автозадача запускает панель и майнер в фоне без окон консоли; панель
остаётся доступной через значок в области уведомлений с командами открыть,
запустить и остановить. При включении или выключении режима Windows один раз
запросит права администратора. Автозапуск по умолчанию выключен; на этом ПК он
включится только после выбора пользователем режима в панели.

Кнопка «Стоп» отправляет майнеру штатный Ctrl+C и ждёт его завершения, чтобы
OneZeroMiner успел сбросить управление вентиляторами. Если процесс не завершился,
панель оставляет статус работающего майнера и сообщает об этом.

Проверка и загрузка обновлений выполняются в отдельных PowerShell runspace-ах,
чтобы не вызывать сценарии из фонового потока без настроенного пространства.

Публичный адрес выплат вводится в панели и сохраняется только в профиле Windows
(`%LOCALAPPDATA%\PearlRigControl\wallet-local.json`). Он не включается в исходники
или установщик. Обновление программы сохраняет этот файл и повторно вводить адрес
не требуется.

Ползунок «Лимит мощности GPU» устанавливает общий предел в ваттах на каждую
видеокарту. Диапазон считывается с обеих карт через `nvidia-smi`; если драйвер
не сообщает диапазон, управление отключено. После нажатия «ПРИМЕНИТЬ» Windows
запросит права администратора, затем предел применяется к обеим картам сразу и
сохраняется для следующих запусков. Это ограничение максимальной мощности, а не
точная регулировка процента загрузки: температура также зависит от охлаждения,
частот и условий в корпусе. Предел можно менять при запущенном майнере.

## Установка

Скачайте `PearlRigControl-Setup.exe` из GitHub Releases и запустите. Установщик
включает OneZeroMiner 1.8.3 из [официального релиза](https://github.com/OneZeroMiner/onezerominer/releases/tag/v1.8.3)
и размещает его в подпапке `miner`. Панель автоматически использует этот файл;
майнинг начинается только после нажатия «ЗАПУСТИТЬ». Для установки частот, лимита
мощности и вентиляторов Windows запросит права администратора для самого майнера;
панель остаётся обычным окном. Установка не запускает майнер.
Для алгоритма Pearlhash OneZeroMiner сообщает о комиссии разработчика 1%.

Сборка проверяет SHA-256 архива майнера перед включением в установщик.

В закрытом репозитории GitHub может показывать 404, если пользователь не вошёл в
аккаунт с доступом к репозиторию.
